# Session — 2026-05-08

## Goal

Stand up micro.film as a real product surface, ship it to the purchased
domain, settle the brand and theme, and produce a high-quality sample
film page that looks like a real streaming experience.

## What landed today

### Project scaffold

- New Next.js 16 app at `apps/micro.film` (App Router, Tailwind v4,
  TypeScript, Geist + Instrument Serif via `next/font`).
- Routes:
  - `/` — landing page
  - `/studio` — slate-style creator interface
  - `/blog` and `/blog/[slug]` — editorial notes
  - `/api/runs` — prototype run contract (no provider calls yet)
  - `/watch/[slug]` — sample film page (added this session)

### Visual system (locked)

- Cinematic palette: warm celluloid black, ivory key, amber accent.
- Typography pairing: Instrument Serif for display + italic, Geist for
  UI, Geist Mono for technical labels.
- Brand motif: filmstrip with sprocket holes, used across hero,
  dividers, posters, blog frames, and player.
- Reusable primitives: `components/FilmStrip.tsx`,
  `components/SiteChrome.tsx`.
- Style guide locked at `docs/style-guide.md` (v0.1).

### Information architecture

- Reframed product around making short, vertical micro films and
  sharing to TikTok, YouTube Shorts, and Instagram Reels.
- Established vocabulary:
  - Micro film = the form, ≤ 3 minutes.
  - Scene = the render unit, 15s, 9:16.
  - Cut = the assembled sequence.
- Removed earlier drama-only framing; product now reads as a film
  studio for any creator.

### Sample film: "The Window Across the Way"

- New `/watch/[slug]` route with the ReelShort-style two-column
  layout: vertical 9:16 player on the left, scrollable detail panel
  with episode grid on the right.
- Sample series with 32 episodes, first 3 free, remainder locked.
- Tags, plot, frame markers, like/save/share counts, and an episode
  grid styled with the filmstrip motif.
- Linked from the landing page Concepts section.

### Production

- Custom domain `micro.film` configured on Vercel:
  - Apex serves production.
  - `www.micro.film` 308 redirects to apex.
  - Vercel nameservers `ns1.vercel-dns.com` / `ns2.vercel-dns.com`.
- Multiple production deploys throughout the day; current state aliased
  to `https://micro.film`.

## Decisions

- The studio renders **scenes**, not "clips." Marketing must keep this
  language.
- Amber is the only chromatic accent in v0.1. No pink, no blue, no
  emerald introduced into core surfaces.
- Sample film is a thriller, not a drama: a quiet, suspense-led story
  to demonstrate the format works for any genre.
- Provider names (e.g. specific image / video model IDs) appear in the
  studio render queue and internal API output but not in marketing copy.
